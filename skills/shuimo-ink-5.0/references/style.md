# 笔墨与金墨标准

本文件是材料规则的唯一权威来源。保留现代感、笔墨系统、颗粒和结构色；金墨按颗粒沉积规范执行。

## 宣纸与墨色

采用暖白、仅微带米色的生宣：基准 `#f7f4ea`，范围 `#f4efdf` 至 `#faf8f0`。纸纤维和细砂触感应能看见，但不成为同等密度的噪点滤镜。不要黄褐旧纸、霉斑、褪色、扫描复刻感或立体纸张阴影。

| 墨层 | 色彩参考 | 工作 |
|---|---|---|
| 焦墨 | `#1a1712` | 最深、干涩、粒感强；少量点睛和关键转折 |
| 浓墨 | `#2e2a22` | 承担主要形体、结构与重量 |
| 重墨 | `#57503f` | 中间层、暗部、过渡 |
| 淡墨 | `#8f8671` | 远层、次要形与疏朗过渡 |
| 清墨 | `#c9bea4` | 极淡水痕、空气层、进入纸白 |

色值是视觉参考，不是逐像素调色保证。不要用纯黑 `#000000` 均匀填涂。暖中性墨不要被画成整张棕褐色。

## 干湿浓淡焦不是灰度滤镜

- 湿墨呈吸水、沉积与渗化；淡墨退后，重墨衔接，浓墨立形，焦墨点睛。
- 按湿 → 淡 → 重 → 浓 → 焦理解叠墨关系，不要求画面从左到右依次排色。
- 用少量长而连贯、有起承收的笔势建立主形；2–8 个关键笔势是概括手段，不是全图笔数限制。
- 长笔势不是大量细长线纹；枯笔的断续来自同一次书写的摩擦，不是碎短笔反复描边。
- 浓墨有体积，焦墨只点关键；背景用淡、清墨退开。保留近实远虚、近浓远淡、尺度和遮挡的纵深。空气感不能洗掉主结构。
- 边缘软硬相济：湿边可洇，焦墨与枯笔可清晰。

笔法气质参考为写意约 42%、泼墨约 28%、没骨约 16%、工笔约 10%、白描约 4%。这些是风格配重，不是五个互斥分区或必须量化的配额：写意主导，泼墨造气氛，没骨成形，工笔只确认关键局部，白描最少。不要把百分比抄入提示词。

## 颗粒：有三个层级，但只有一个重点

1. 纸纤维：纸面可感知的底层肌理。
2. 墨颗粒：积墨、焦墨、枯笔和飞白内的砂质层。
3. 金墨颗粒：附在纸墨结构上的局部矿物沉积。

选一处主要颗粒焦点，让粒感随墨量与结构聚散。允许全纸有纤维，不允许全图同密度撒颗粒、铺噪声或星点。全图平均 = 没有重心 = 变成"图标"。

## 金墨：先有沉积，局部才反光

目标是**粗糙纸面与墨层上可见的矿物金颗粒、碎片和断续薄层铺附**，不是只有高光闪烁。体现"聚集 → 过渡 → 散开"：局部形成不规则较密的颗粒团或薄片，边缘破碎，中颗粒沿笔势过渡，最后少量细粒收尾；保留底墨与纸面的间隙。

- 同时有少量较大可见颗粒、中颗粒和少量细粒；不能清一色细金粉。
- 一个主金墨区，必要时一至两个更小呼应；依附主笔势、墨层转折或主焦点。
- 若借用原图真实光线，方向应有依据；不另造金色光源。
- 保留哑光颗粒、片状沉积与少量受光反射的区别，不做镜面金属、金色渐变、亮黄填色、金属描边或均匀撒金。
- "堆叠"描述微观颗粒与颜料层次，不做立体金块、浮雕或厚重金边。

金墨默认启用但保持局部。用户要求无金墨时关闭这一材料层，不影响笔墨和纸纹。

## 单一矿物强调色

默认选一个来自内容依据的色相，以矿物或植物颜料转译：朱砂 `#c3272b`、胭脂 `#9e3b4f`、石青 `#2a5c8a`、石绿 `#3e7a5e`、藤黄 `#e8b923`、赭石 `#a05a2c`、花青 `#3b4f8f`。可留空让模型按照片自动选。

让强调色有饱和度和起收笔，像毛笔一笔"写"出来——有起笔收笔、有笔锋飞白，沿已有形、方向或间隙承担导向、配重、衔接或焦点，成为构图的一部分而不是独立摆着的色块。暗墨底上放高饱和的色让它在灰调里"跳"出来，但面积始终小。淡墨为主的画面，用饱和度特别高但占比特别小的颜色点睛。

允许同一颜料少量淡化回应，但只有一个高饱和主色相；最多一处小回声，回声不超过该强调色总面积的约 15%。执行结构移除测试：去掉颜色后，方向、平衡或焦点应有所损失；若完全不变，改变附着位置，而不是凭空增加有色物体。

统一口径：暖中性墨占可见着墨/着色标记的至少约 80%；普通矿物强调色不超过约 10–15%。金墨不占用"单一矿物色"的色相名额，但矿物色与金墨合计控制在约 20% 内。若颜色过多，先减彩色面积或增加已有墨势，不加新对象。禁荧光色、糖果色、纯 RGB 霓虹色。

内容是无彩色照片时，不声称观察到不存在的原色；先询问强调色，或保留暖中性墨与局部金墨，不擅自染出新的场景色。纯文字模式可按用户指定色或文字中的物体颜色选色。

## 留白与疏密

留白 ≥ 45%（计白当黑），**画面绝不铺满**；宁可留白偏多，不可画满。留白要承担"空间/呼吸/尺度/情绪"中至少一种功能，不是机械留边。

- 疏密对比：一密一疏引导视线（如左密右疏）。
- 主次靠墨色深浅 + 笔触繁简建立：主体用长笔势浓墨写形，次重点用淡墨线/简笔带过。
- 只做足 1–2 个主焦点：焦点用繁复笔触，次重点、中景用线条带过，不处处精致。
- 内容多时"减重 + 概括"：少墨、疏朗，次要元素简笔带过。

## 现代气质

保留淡雅、空气感和现代编辑插画气质；借鉴浓墨层次、疏密节奏、泼色与墨共存、动物传神等具体技法，不把画家姓名或仿古模板塞入提示词。不要题跋、印章、落款、均匀皴法或传统装裱感。严格避免：仿古做旧、满铺皴法、工笔细描到仿古程度、传统落款构图感。
